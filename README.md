# How To Go To — Japan

Путеводитель по Японии. Первый проект серии «How To Go To» (как поехать в...).

## Структура

```
japan-guide/
├── index.html          # Главная
├── culture.html        # Культура и этикет (основная страница)
├── regions.html
├── itineraries.html
├── food.html
├── tips.html
├── css/
├── js/
└── images/
```

## Как открыть

1. Распакуй архив.
2. Открой `index.html` в браузере.
3. Переходи по меню.

## Дальше

Можно добавлять страницы других стран по тому же принципу:  
`howto-go-to-italy.html`, отдельный репозиторий или папки стран.
